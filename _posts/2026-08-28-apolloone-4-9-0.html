--- layout: post title: "ApolloOne 4.9.0" date: 2026-08-28 20:40:00 +0000 summary: "A setup flow on first launch, a color space choice for exported images, and official support for the Sony RX10 V. Various enhancements and bug fixes." ---
  • NEW! A setup flow on first launch — choose where ApolloOne writes your metadata, grant the folder access it needs, and see the two things worth doing first. You can run it again at any time from "Help > Run Setup…".
  • NEW! Choose the color space of exported images — keep the original color space (the default), or convert to sRGB, Display P3 or Adobe RGB (1998). RAW files export as Display P3.
  • NEW! Official support for Sony RX10 V via RawBridge™.
  • Fixed the Quick Edit sliders having no effect for some users.
  • Fixed the single-image view occasionally appearing behind the thumbnails in Contact Sheet mode.
  • Esc now closes the "Add Keywords…" panel — and stops a metadata load in progress.
  • Faster metadata saves — and keywords shared by the selected images now display even when each file lists them in a different order.
  • Various enhancements and bug fixes.
