ApolloOne GO FAQ

Questions worth answering before you download. If yours isn't here, ask us — and once the app is installed, Getting Started and a longer FAQ live in its Settings.

Is ApolloOne GO a general image viewer for JPEG, HEIC, TIFF, PNG or GIF?

No — it is a culling tool for the shoot, not a photo browser. ApolloOne GO shows your camera's files: every RAW, and — since version 1.1.0 — any JPEG or HEIF (HIF) that has no RAW of the same name beside it. TIFF, PNG and GIF files are not shown.

A RAW+JPEG pair is listed once, as the RAW — listing the JPEG alongside would show every shot twice and put your Pick and Reject tags on the wrong file. When you copy, move, delete or AirDrop, you can include the matching JPG/HIF files so the pairs stay together.

The JPEG-only rule exists for a real workflow: pre-release capture. Current Nikon Z bodies record those bursts as JPEG only — in GO they appear right beside your RAWs and can be culled like any other shot, AF points and face overlays included.

To be clear about what Pick and Reject "tags" mean: these are standard Finder color tags, the same ones you could apply by hand in Finder. Your RAW files are never modified — see below.

And a folder holding only JPEGs or HEIFs? It displays fully — with no RAWs around, every file is an orphan — so since 1.1.0 GO doubles as a fast culling viewer for JPEG shoots. One caveat: tapping a JPEG in the Files app still opens Quick Look, not GO — browse the folder from GO's own Contact Sheet.

Which RAW formats does ApolloOne GO support?

Adobe DNG, Canon (.CR2, .CR3, .CRW), Fujifilm including compressed RAF, Nikon including HE and HE* NEF, Olympus and OM System, Panasonic, Pentax, Samsung, Sigma Foveon X3F, Sony (.ARW, .ARQ) and Hasselblad.

That is the same range as ApolloOne on the Mac, with one exception: GoPro GPR is not supported on iPhone and iPad. If your camera's RAW files don't open, tell us — that is usually how a format gets added.

Can I connect my camera directly?

Yes. Plug the camera body into the USB-C port and GO browses the card inside it, using the same protocol the Photos app uses for import — so it works even with cameras that never mount as a drive. You get a thumbnail grid grouped by capture day, full-screen embedded JPEG previews with pinch-zoom and AF point and face overlays, and then you select the keepers and import only those. The rejects never leave the camera.

A memory card in a USB-C reader works the same way, and either source can be culled before a single file is copied. If your camera doesn't show up, a camera setting is usually the reason.

Do I need a Mac, or ApolloOne on the Mac?

Neither. ApolloOne GO is complete on its own: browse, view, cull and import with no Mac involved. If you do run ApolloOne on a Mac, your culling decisions travel there automatically — but that is a bonus, not a requirement.

How do my Pick and Reject decisions reach my Mac?

Each decision becomes a standard macOS Finder color tag — green for a pick, red for a reject. When the folder lives in iCloud Drive, those tags sync to your Mac on their own. Open the folder in Finder or in ApolloOne and the decisions are simply there. No export step, no database, no proprietary sidecar files.

I use Lightroom, not ApolloOne — can I still use GO?

Yes, with one step on the Mac. GO records its decisions as Finder tags, which Lightroom doesn't read. ApolloOne on the Mac converts them as it imports the card: picks become XMP pick metadata and rejects become the XMP standard's rejected rating, both written to the sidecar file Lightroom reads. The chain is cull in GO → import the card with ApolloOne → import into Lightroom with the decisions already attached.

Import on the iPad instead and that conversion doesn't happen — the decisions stay as Finder tags, which is exactly right for Finder and ApolloOne, but invisible to Lightroom. So if Lightroom is your editor, ApolloOne is the piece that makes GO's culling land in it — and it does the rest of the desk work too: HDR RAW viewing, EXIF, AF points, Quick Edit.

Can I try it before buying?

Yes. The download is free and the first 14 days are a full trial with every feature unlocked — no account, no sign-up, no card details. After 14 days ApolloOne GO stops working until you unlock it with the one-time in-app purchase. Two weeks is deliberately enough for a real shoot, not just a look around.

Is it a subscription?

No. One in-app purchase unlocks the app permanently. Nothing to renew, no account to create.

Which devices does it run on?

iPhone and iPad running iOS or iPadOS 16 or later. The interface adapts to both, and on an iPad with a hardware keyboard the whole culling pass can be driven from the keys — arrows to navigate, P to pick, X to reject.

Is there a Mac version of GO?

ApolloOne GO is for iPhone and iPad. On the Mac, ApolloOne is the full application — GO is its field companion, not a replacement.

My camera isn't detected over USB-C

First check the cable: charge-only USB-C cables are a common cause, and the cable must carry data.

  • Recent Fujifilm bodies (GFX100S II, GFX100 II and others): in the Network/USB Setting menu, set USB POWER SUPPLY/COMM SETTING to POWER SUPPLY OFF/COMM ON, and choose the USB CARD READER connection mode. On the factory AUTO setting the camera may pick charging over communication and never appear.
  • Nikon Z8 and Z9: turn Airplane mode off — these bodies will not open a USB data connection while it is on — and set the camera's USB connection mode to PTP.

Which card readers work?

SD readers draw little power and usually work plugged straight in. Power-hungry readers — CFexpress especially — can draw more than an iPhone or iPad USB-C port supplies; partway through a long import the reader browns out and the remaining copies fail. The fix is external power: run the reader through a powered USB-C hub, which a USB-C power bank can feed in the field. Nothing already copied is lost, and running Import again resumes where it stopped.

Does it edit RAW files?

No. GO views and culls — it is not a RAW developer. Quick Edit adjustments you made in ApolloOne on the Mac do travel with the files, and GO applies them on display, so an image you adjusted at your desk looks the same in the field.

Does it import into the Photos app?

No. GO works with files and folders through the Files app — iCloud Drive, On My iPhone or iPad, external drives and memory cards — and imports land in a folder you choose. The Photos library is neither read nor written: Photos assets can't carry the Finder tags that make the round trip to your Mac work.

Will it change my original files?

No. Your RAW files are never rewritten. Picking and rejecting sets a standard Finder color tag — the same tag you could apply by hand in Finder. A Finder tag is file metadata kept by the operating system alongside the file; not a single byte inside the RAW is touched, exactly as when you tag a file in Finder on your Mac.

Copy, move and delete happen only when you ask for them, and each is confirmed before it runs.

Does it need an internet connection?

Browsing, viewing, culling, importing and AirDrop all work fully offline — which matters, given where culling usually happens. A connection is needed only to make or restore the purchase, and for iCloud to carry your decisions home.

Does it play video?

No. ApolloOne GO handles RAW still images only. ApolloOne on the Mac plays video.
