ApolloOne Community Scripts

Five AppleScripts that fill in metadata for the photos you select in ApolloOne: keywords from Claude AI, then the title, headline, description and location. They need ApolloOne 5.0.0 or later with the Max Edition.

What's in the download

  • Set keyword using Claude AI sends each photo to Claude and adds the species name to its keywords.
  • Set title via keywords sets the title to the photo's last keyword, and puts a copy with underscores in the Comment field for batch renaming.
  • Set description and headline builds the headline and description from the title, location and city.
  • Set title description and headline via keywords does the two above in one pass.
  • Set location information writes location, city, state, country and country code, with the city picked from your own list.

Install

  1. Download the scripts with the button below and unzip them.
  2. Open Terminal, type bash and a space, drag install.sh from the unzipped folder into the Terminal window, and press Return. It copies the scripts to ~/Library/Scripts/ApolloOne/ and asks whether to set up the Claude AI script as well.
  3. Turn on the Scripts menu: open Script Editor (in Applications > Utilities), choose Script Editor > Settings > General, and select "Show Script menu in menu bar". A scroll icon appears in the menu bar.

Run a script

Select the photos in ApolloOne (⌘A selects all), click the scroll icon in the menu bar, and choose a script from the ApolloOne submenu. ApolloOne's progress bar above the status bar shows how far it has got, and a notification appears when it finishes.

Keywords with Claude AI

This script needs your own Anthropic API key. Get one from the Anthropic Console; the API is paid per use with no free tier, and a Claude subscription doesn't cover it. When install.sh asks, answer yes and paste the key. It installs the two Python packages the script uses, copies its helper image-subject.py to ~/Library/Application Support/ApolloOne Scripts/ and stores the key in your keychain.

  • Each photo is resized to 1024 pixels and sent to Anthropic on your key and billing. With Claude Sonnet, the default, that comes to about $2.40 per 1,000 photos. Claude Opus, for hard look-alike species, is about $7.
  • RAW files work. macOS decodes each one to make the 1024-pixel copy, which adds about a second per photo, and a camera macOS doesn't support yet is skipped. ApolloOne writes the metadata of RAW files to an XMP sidecar.
  • Claude can name the same animal differently from another angle or pose. For a series of one animal, select only the clearest photo, run the script, and give the rest of the series the same keywords.
  • ApolloOne's built-in AI Keywords sends nothing to Anthropic; it runs on Apple's Private Cloud Compute. It also keywords a whole closed stack from its key photo.

The city list

Set location information asks for a plain text file (UTF-8) with one place per line, city and state separated by a semicolon or a comma:

Amsterdam;Noord-Holland
Utrecht;Utrecht

The headline and description join the fields with "at" and "near". For other words, open the script in Script Editor and change the two lines at the top.
